# Datacenter Siege

A browser siege game. A hyperscale datacenter is going up on Cedar Creek. Throw rocks at it with a trebuchet and wreck sections faster than the crews can rebuild them. If the developer's budget runs out, the building comes down and the forest, creek and wildlife come back. If all 72 sections stand at once, the datacenter goes online and you lose.

**Play:** https://bhumphrey.github.io/datacenterseige/

## Controls

- Drag anywhere and pull back to aim, then release to fire
- `↑` `↓` angle, `←` `→` power, `Space` fire
- `M` toggles all sound, `B` toggles music

Everything is in one `index.html`: canvas graphics and Web Audio sound, with no build step and no dependencies.
